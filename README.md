# World Environment & Sky Settings (Xogot 3D Tutorial)

This project contains the example scenes used in the **Xogot 3D Modular Series -
World Environment** tutorial by **Erin Uptegrove**.  

It demonstrates how to add and configure a `WorldEnvironment` node in **Xogot**
- the iPad & iPhone port of the Godot Engine - and explores the visual settings
that shape the look and feel of a 3D scene.

The project includes sample scenes for experimenting with background modes, sky
types, ambient light, and more.

---

## Features
* Adding a **WorldEnvironment** node from the Scene Tree
* Adjust key environment properties for immediate visual feedback
* Configure different **Background Modes** depending on your scene’s needs
* Work with **Panorama**, **Procedural**, and **Physical Sky** modes
* Modify additional settings such as **Ambient Light** to refine overall scene lighting
